# Настройка обновления

Создайте отдельную PostgreSQL базу для прототипа. Выполните migrations/001_student_state.sql через SQL editor провайдера. В Vercel Environment Variables добавьте DATABASE_URL с pooled connection string провайдера, с проверкой TLS согласно его инструкции. Не выключайте проверку сертификата. Секреты не коммитьте. SESSION_SECRET и AI_API_KEY остаются на сервере. Сделайте Redeploy.

Теперь состояние хранится по owner_id из серверной сессии. Cookie состояния больше не читается. Старые данные браузера в базу не импортируются: начальные записи создаются из вымышленного каталога. Повторный вход не сбрасывает заявки. Сброс демо удаляет изменения только текущего владельца. Конфликт одновременных записей возвращает 409, без перезаписи новых данных старой копией.

Без DATABASE_URL допускается только локальное хранилище в памяти, теряющее данные при перезапуске. В production отсутствие базы вызывает ошибку: это исключает скрытое возвращение к непостоянному хранению.

Проверки: npm ci; npm run lint; npm run typecheck:api; npm run build; node --import tsx tests/state-isolation.mts. Последний тест по умолчанию использует локальный memory adapter. Для проверки PostgreSQL задайте DATABASE_URL тестовой базы и запустите его отдельно; записи имеют демонстрационные данные.

Новый блок содержит приоритеты по текущим оценкам, ближайшую пару, мастер трёх заявок с явным подтверждением и недельный план с чётностью недель. Виза и пересдачи не получают выдуманных сроков: текущая модель данных не содержит машиночитаемых дедлайнов.

English переключает новый помощник, план, краткий профиль, сводку оценок/заявок и нижнюю навигацию. Старые подробные экраны и содержимое учебных данных остаются русскими. Это начальная локализация, не полный перевод приложения. Перед конкурсом нужен перевод старых форм, ошибок, уведомлений, профиля и входа с проверкой всех маршрутов.

Настройки доступности: размер текста, контраст и уменьшение анимации сохраняются только как предпочтения этого браузера. Они не содержат учебных данных. Полное соответствие WCAG не заявляется: обязательна браузерная проверка 360 px, клавиатуры и скринридера.

Живой Gemini, база провайдера и мобильный рендер в этой итерации не проверены. Проверены компиляция и API со storage adapter. Queue в памяти не является глобальным лимитером Vercel. Для нагрузки нужен общий limiter; retries ограничены бюджетом, неверные ключи/неподдерживаемая модель не повторяются.
