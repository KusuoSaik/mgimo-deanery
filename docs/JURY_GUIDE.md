## Путь студента

1. Войдите как Дмитрий. Откройте «Микроэкономика» из «Что требует внимания»: баллы, результаты сессии, демо-запись на консультацию. Запишитесь и обновите страницу — запись сохранена.
2. «Расписание» → «Неделя»: все дни и переносы видны вместе. «В календарь» скачивает .ics для выбранной недели; файл импортируется в календарь, время — МСК. Это снимок, он не обновляется автоматически.
3. «Заявки» → «Новая заявка»: создайте «Справка для учебной стажировки». Данные студента берутся из сессии. Посмотрите срок и историю.
4. В отдельном приватном окне войдите как сотрудник: запросите уточнение. В кабинете студента нажмите «Обновить данные», ответьте. Сотрудник обновляет очередь и проводит заявку по этапам до готовности. Студент обновляет данные и скачивает PDF.
5. В другом приватном окне войдите как Алексей. Профиль, расписание, баллы и заявки другие; заявка Дмитрия отсутствует. Автотесты дополнительно пытаются изменить чужую заявку через API и получают отказ.
6. Покажите уведомления, настройки доступности и English. Ассистент не отправляет заявку без подтверждения. При недоступном ИИ используйте обычную форму — она работает независимо.

Для видео используйте ширину 360 px и отдельный десктопный кадр. Не объявляйте баллы жюри заранее.
