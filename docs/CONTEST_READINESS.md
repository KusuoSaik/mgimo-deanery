## Проверки текущей доработки

- `npm run lint` — успешно.
- `npm run typecheck:api` — успешно.
- `npm run build` — успешно. Предупреждение о размере отдельного PDF-чанка сохраняется; он загружается динамически при скачивании PDF.
- `npm run build:server` — успешно.
- `npm test` — успешно с memory adapter, затем с отдельной PostgreSQL 16.
- `npm run test:storage` — успешно: состояние и ограничение входа сохраняются между независимыми процессами; чужой owner изолирован.
- `npm run test:ai:shared` — успешно: общий слот ИИ на два процесса.
- `npm run test:browser` — успешно на PostgreSQL с Chromium: 360/430/1280 px, две студенческие сессии и сотрудник, консультация, уточнение и ответ, этапы, отмена, загрузка PDF и .ics, offline-предупреждение, RU/EN, настройки доступности, фокус модального окна, защита от позднего ответа ИИ другого аккаунта.
- `npm audit --omit=dev` — 0 найденных уязвимостей на момент проверки. Полный audit сообщает moderate для minimatch и цепочки инструментов ESLint; это зависимости разработки. Они не включаются в финальный runtime Docker-образ. Принудительная замена major minimatch не выполнялась без подтверждения совместимости upstream.
- Docker production-образ — собран (в Cloud с временной прокси/CA-адаптацией Dockerfile). Запуск с NODE_ENV=production и PostgreSQL проверен: SPA/API, healthz, два входа, Secure/HttpOnly/SameSite cookie, создание/отмена заявки, запрет чужой заявки, Origin и HTTP-заголовки. Публичные TLS/домен не проверялись.
- GitHub Actions настроен на такую же последовательность с отдельной PostgreSQL; удалённый workflow в этой сессии не запускался, поскольку код ещё не отправлялся в GitHub.

## Проработанность идеи и использование ИИ

Приоритеты связывают домашнюю страницу с проблемным предметом и заявкой. Запись на демо-консультацию и переписка по уточнению замыкают сценарий «увидел проблему → сделал следующий шаг → получил результат». Экспорт позволяет использовать учебный план в личном календаре. Экран не выдаёт декоративные элементы за реальные государственные или вузовские сервисы.

Процесс текущей доработки описан в PROCESS_007.md и PDF: инструменты, фактические запросы, реконструированные рабочие постановки, ошибки и исправления, архитектура, скриншоты до/после, честная граница ручной работы. Список лицензий — THIRD_PARTY_NOTICES.md. AGENTS.md задаёт проверяемые ограничения следующим ИИ-итерациям. Реальные опросы и неподтверждённые прошлые этапы не выдуманы.
