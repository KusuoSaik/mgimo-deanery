# Правила работы ИИ с конкурсным прототипом

## Перед изменениями
- Прочитайте README, CLAUDE.md и docs/CONTEST_READINESS.md. Сохраните существующие изменения пользователя.
- Это конкурсный концепт, не официальный сервис МГИМО. Только вымышленные данные; не используйте официальный логотип.
- Контракт src/types.ts сохраняйте. Используйте type-only imports. Компоненты — React, Tailwind, lucide-react.

## Инварианты
- Личность определяется серверной HttpOnly-сессией. ownerId в теле только проверяет принадлежность отложенной операции, но не даёт прав.
- Чужие заявки/консультации проверяйте негативными API-тестами. Этапы заявок изменяет только сотрудник.
- Не передавайте пароли, хеши, SESSION_SECRET, DATABASE_URL и AI_API_KEY в клиентский bundle или логи.
- Production использует PostgreSQL и все SQL-миграции; память допустима только для локальной разработки.
- Ни один экран не должен обещать настоящие ЭЦП, QR-пропуск, запись к реальному преподавателю или связь с настоящим деканатом.
- ИИ предлагает действия, студент подтверждает отправку. Ошибка провайдера не блокирует основные разделы.

## Приёмка
- npm run lint; npm run typecheck:api; npm run build; npm run build:server; npm test.
- На отдельной PostgreSQL: npm run test:storage; npm run test:ai:shared; npm run test:browser.
- Проверьте 360/430/1280 px, RU/EN, крупный текст, контраст, клавиатуру и сбои сети.
- Указывайте фактический результат и ограничения. Не выдумывайте интервью, инструменты, историю промптов, проверки production или баллы жюри.
- Новая функция должна решать конкретную задачу студента. Не подменяйте серверную безопасность клиентской фильтрацией.
