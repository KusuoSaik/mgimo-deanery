### 2. Реальная система авторизации

#### ✅ Двухфакторная проверка (2FA)
- При успешном логине генерируется **4-значный код** (видно в консоли браузера)
- Таймер повторной отправки: **30 секунд**
- Можно запросить новый код (регенерируется автоматически)
- При неверном коде показывается ошибка и очищаются поля
- После верификации код истекает и сессия блокируется

#### ✅ Валидация учетных данных
- Проверка существования email в базе
- Проверка пароля
- Красные подсвеченные поля при ошибке
- **Анимация "тряски"** формы (shake animation) при неправильных данных
- Понятные сообщения об ошибках

#### ✅ Регистрация новых аккаунтов
- Вкладка **"Регистрация"** на экране входа
- Валидация полей:
  - Email обязательно должен заканчиваться на `@my.mgimo.ru`
  - Пароль минимум **6 символов**
  - ФИО, факультет, курс, статус (Студент/Староста/Иностранный студент)
- Все новые аккаунты сохраняются в **localStorage**
- Новый аккаунт сразу готов к входу (заполняются поля для входа)

### 3. Система управления аккаунтами и персональными данными

#### ✅ Персональные данные для каждого аккаунта
- Каждый аккаунт имеет **собственные**:
  - Расписание
  - Оценки (БРС)
  - Заявки
  - Уведомления
  - История чата с ИИ-ассистентом
- Данные сохраняются в `localStorage` с ключом, привязанным к ID аккаунта

#### ✅ Переключение аккаунтов
- В профиле добавлена кнопка **"Переключить аккаунт"**
- При переключении:
  - Текущие данные сохраняются
  - Загружаются данные нового аккаунта
  - Интерфейс обновляется со всеми персональными данными
- Быстрый список других аккаунтов в профиле

#### ✅ Выход из системы
- Кнопка **"Выйти из аккаунта"** очищает состояние авторизации
- При повторном входе восстанавливаются все данные из localStorage

## 🚀 Как использовать

### Быстрый старт
1. Откройте приложение
2. Нажмите на один из демо-чипсов внизу экрана входа
3. Поля email и пароль заполнятся автоматически
4. Нажмите "Продолжить"
5. **В консоли браузера (F12 → Console) скопируйте 4-значный код**
6. Введите код в поля 2FA
7. Готово! Вы вошли в систему

### Регистрация нового аккаунта
1. На экране входа нажмите вкладку **"Регистрация"**
2. Заполните форму:
   - ФИО
   - Email (должен заканчиваться на `@my.mgimo.ru`)
   - Пароль (минимум 6 символов)
   - Выберите факультет, курс, статус
3. Нажмите **"Зарегистрироваться"**
4. После успешной регистрации поля входа заполнятся автоматически
5. Нажмите вкладку **"Вход"** → нажмите "Продолжить"

### Переключение между аккаунтами
1. Откройте **Профиль** (вкладка ПП внизу)
2. Нажмите **"Переключить аккаунт"**
3. Выберите другой аккаунт из списка
4. Данные тут же обновятся

### Выход из системы
1. Откройте **Профиль**
2. Нажмите **"Выйти из аккаунта"**
3. Вы вернётесь на экран входа
